# Two-disk nonconvex differential inclusion: Plotly publication figures

Companion 3D figure package for the relaxation-gap benchmark

    xdot(t) in g(t, x(t)) + E(t),
    E(t) = D(c(t), r)  U  D(-c(t), r)      (NONCONVEX: union of two disks),
    c(t) = R_{theta(t)} (0.4, 0)^T,  theta(t) = pi t / T,  r = 0.1,

with target x1 generated by the relaxed selection xi = 0 in conv E(t) \ E(t)
(so dist(0, E(t)) = |c| - r = 0.3 uniformly in t). The script first solves

* (A)  the hard selector parametrization (disk mode per node, zero-order hold,
       within-disk local coordinates; L-BFGS-B + greedy mode flips)
       -> admissible by construction, dist(xi, E) = 0 exactly, chattering;
* (B1) the soft distance-residual penalty with low smoothing
       -> chatters, residual spikes to ~0.3 at every disk-to-disk crossing;
* (B2) the soft distance-residual penalty with high smoothing (proxy for the
       finite bandwidth / spectral bias of a smooth NN surrogate)
       -> settles on a relaxed selection dwelling inside the gap
       (Filippov-Wazewski convexification; the residual has a positive floor),

caches the solution in `outputs/twodisk_solution.npz`, and generates
publication-style Plotly figures with a light background:

1. `01_velocity_double_tube_light` - twisted DOUBLE tube
   `F(t,x(t)) = g(t,x(t)) +/- c(t) + D(0,r)` along the hard trajectory, with
   the selected velocities `v(t_i) = g + xi` jumping between the two tubes.
2. `02_selector_double_cylinder_light` - selector `xi(t)` inside the two
   rotating disk cylinders `E(t)`; the faint gray surface is the stadium hull
   `conv E(t)`. The hard selector (green) has dist = 0 identically; the soft
   selector (colored by `dist(xi, E)`) concentrates in / near `conv E(t)` and
   dwells in the gap between the disks. The chattering soft variant (B1) is
   included as a hidden trace - click its legend entry in the HTML to show it.
3. `03_state_trajectories_light` - state trajectories x(t) for (A), (B1),
   (B2) against the relaxed reference; all reach the target, so the terminal
   cost detects nothing - the gap is visible only in the inclusion residual.

Each figure is exported as `.png` (recommended for LaTeX/PDF submission,
Plotly 3D PDF export is rasterized internally), `.pdf`, and interactive
`.html`; `combined_light_figures.html` bundles all three.

## Quick run

```bash
chmod +x run_export.sh
./run_export.sh
```

The output files will be written to `outputs/`. The optimization (a few tens
of seconds) runs once and is cached; add `--recompute` to re-solve:

```bash
python src/generate_twodisk_figures.py --out outputs --scale 3 --formats png,pdf,html --recompute
```

## Custom output directory and scale

```bash
./run_export.sh my_outputs 4
```
